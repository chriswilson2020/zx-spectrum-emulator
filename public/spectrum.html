    ZX Spectrum web emulator for games, BASIC and Z80 development

    This browser-based emulator recreates the original 48K Sinclair ZX Spectrum around a validated Z80 CPU core, 48K memory map, keyboard matrix, beeper, 50 Hz display and ULA timing behavior. It runs as a JavaScript application in a modern web browser, with no desktop emulator installation required.

    It is deliberately more than a quick game launcher. The same page combines tape and snapshot loading with Sinclair BASIC import/export, RZX playback, instruction stepping, reverse stepping, rewind history, live registers and flags, disassembly, memory inspection, raster timing and source-listing tools.

    TAP and TZX tape support

    Open .tap tape images and standard-speed .tzx data blocks in the browser. Inspect tape blocks, fast-load supported BASIC and CODE header/data pairs, or let standard-speed blocks feed the emulated EAR input.

    SNA and Z80 snapshot support

    Load classic 48K .sna snapshots and compatible .z80 snapshots, including compressed or uncompressed version 1 files and extended snapshots containing the normal 48K pages. Save the current machine as an uncompressed 48K Z80 snapshot.

    Browser Z80 debugger

    Pause execution, step by frame or instruction, step backward, scrub rewind history, and inspect registers, flags, disassembly, memory, raster position and t-states. Load assembly/listing files beside the debugger and search the built-in sjasmplus reference.

    Supported ZX Spectrum file formats

    Format Browser support
    TAP Tape block parsing, inspection, supported fast-loading and standard-speed EAR pulse playback.
    TZX Standard-speed data blocks. Turbo, pure-data and more complex custom-loader TZX timing are not claimed as supported.
    SNA Load classic 48K SNA snapshots.
    Z80 Load compatible 48K Z80 snapshots and save the current state as an uncompressed version 1 Z80 snapshot.
    RZX Step through or play compatible 48K RZX input recordings with embedded or user-supplied SNA/Z80 snapshots.
    BAS / TXT Paste or import Sinclair BASIC source, tokenize it into Spectrum memory, run it, and export editable BASIC text.

    Built-in ZX Spectrum and Z80 debugging tools

    The debugging workbench is aimed at people writing, studying or reverse-engineering Z80 and Spectrum software. It exposes live CPU state, flags, disassembly around the program counter, key memory regions, BASIC state, raster timing and an optional raster overlay. Resizable debugger panels can follow source listings while the emulator runs or steps, and the bounded reverse history allows frame rewind without taking a complete 48K memory copy at every checkpoint.
